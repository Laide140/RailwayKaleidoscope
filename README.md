# 铁路万花筒

一款综合铁路信息查询 App，界面采用 iOS 风格设计。基于 `uni-app`（Vue 2）开发，一套代码可编译到 Android App、iOS App 与 H5。

> 目前仅支持安卓版，尚未上架应用商店，需通过官网下载 APK 安装；苹果版已暂停开发（只是我自己证书没了，不影响你进行编译）。

- 官网：https://rail.laide.asia （提供 APK 下载与项目介绍）

## 功能

### 出行服务
- **车次查询**：输入出发/到达站中文名查询车次列表
- **时刻表**：查看车次全部停靠站、到发时刻，支持去程/返程切换
- **实时位置**：地图展示列车当前位置，2 秒自动刷新
- **铁路线路图**：查看车次运行线路轨迹

### 车站服务
- **车站大屏**：车站电子大屏样式的到发信息
- **检票口查询**：查询检票口与站台信息
- **交通查询**：车站周边公交、地铁、停车场接驳
- **车站代码**：全国车站电报代码 / 拼音缩写查询

### 路网查询
- **路网地图**：全国铁路线路图（红色铁路、蓝色地铁、虚线隧道），首次需下载约 169MB 缓存
- **运用担当查询**：按车次查车组、按车组查担当记录

### 趣味工具
- **纪念车票**：生成纪念车票图片并保存到相册
- **列车广播**：文本转语音，模拟车站/列车广播（支持讯飞、百度双音源，含预设广播语）

## 自定义 UI

在「我的 → 设置」中可深度自定义：

- **首页布局**：三模式自由切换
  - `分区卡片`：带背景图的分区卡片
  - `宫格`：按分区分组的图标宫格
  - `自定义`：自己拖拽图标搭建的卡片
- **主题色**：10 个预设色 + 自定义调色器（色相/饱和/亮度 + hex 输入），全 App 生效
- **自定义卡片编辑器**：新建卡片、拖拽/点选功能图标、相册上传背景图、修改卡片主题色

## 技术栈

- **框架**：uni-app（Vue 2），`manifest.json` `vueVersion: "2"`
- **图标**：Font Awesome 5
- **设计**：Apple 设计系统风格（SF 字体栈、毛玻璃、iOS 色彩体系）
- **自定义 TabBar**：首页 / 路网地图 / 我的

## 目录结构

```
├── pages/                    # 页面
│   ├── home/                 # 首页（三模式）
│   ├── settings/             # 设置页（布局/主题/密钥/卡片）
│   ├── custom-editor/        # 自定义卡片编辑器
│   ├── section-detail/       # 分区详情页
│   ├── train-broadcast/      # 列车广播
│   └── ...                   # 各功能页面
├── components/
│   └── custom-tabbar/        # 自定义 TabBar
├── common/                   # 公共模块
│   ├── settings.js           # 设置读写与主题应用
│   ├── config.js             # 本地配置文件（密钥等）
│   ├── keys.js               # 密钥解析逻辑
│   ├── features.js           # 功能/分区数据源
│   └── color.js              # 颜色工具

├── store/index.js            # Vuex（含 settings 状态）

│   └── section-*.jpg         # 首页分区卡片背景图（自行放置）
└── pages.json                # 路由与 TabBar 配置
```

## 快速开始

使用 [HBuilderX](https://www.dcloud.io/hbuilderx.html)（App 开发版）打开项目：

1. 菜单「运行」→「运行到手机或模拟器」选择设备
2. 或「运行」→「运行到浏览器」查看 H5 效果
3. 发行：菜单「发行」→「原生 App-云打包」生成 APK

## 首页背景图

首页分区卡片支持自定义背景图，把图片放到 `static/` 目录并命名：

```
static/section-travel.jpg     # 出行服务
static/section-station.jpg    # 车站服务
static/section-tracking.jpg   # 路网查询
static/section-fun.jpg        # 趣味工具
```

推荐 16:9 比例、不低于 1200×675。未放置时卡片使用主题色兜底显示。

## 密钥配置

所有 API 密钥集中管理，**不使用任何插件 / 配置文件框架**：

- **本地配置文件**：`common/config.js` 中的 `keys` 存放默认密钥
- **运行时覆盖**：「设置 → 接口密钥」可切换「官方（默认）/ 自定义」，覆盖值存于本地存储，优先级最高
- 涉及密钥：高德 Web 服务、高德 JS API 及安全密钥
